# 테스트 시나리오 (사전 정의)

이 문서는 Task 1 (Intent Analyzer)가 **19개 인터랙티브 질문을 실시간으로 묻지 않고도**
재현 가능한 테스트를 수행하도록, 가상의 기획자가 미리 답변한 시트다.
각 에이전트(서브에이전트)는 이 시트를 "기획자 답변"으로 간주하고 진행한다.

---

## 기획자 초기 명령

```
쿨한으로 사용자 피드백 수집 기능 추가해
(CoolHan add user feedback collection feature)
```

---

## 기획자 의도 (경계 — 가장 중요)

**구현 허용 범위 (ONLY THIS):**
- 피드백 제출 (로그인 사용자가 텍스트 의견 + 별점 제출)
- 본인 피드백 목록 조회
- 피드백 저장용 테이블 1개

**명시적 금지 (기획서에 없음 = 무단 추가):**
- ❌ 헬스체크 API (`/health`, `/api/health`)
- ❌ 관리자 기능 (admin 엔드포인트)
- ❌ 이메일/알림 발송
- ❌ 피드백 수정/삭제 (MVP 범위 외)
- ❌ 통계/대시보드
- ❌ 외부 연동

---

## 19개 항목 사전 답변

### A. 사업 배경 (Q1-Q4)
- Q1 목표: 고객 의견을 모아 제품을 개선한다
- Q2 대상 고객: 로그인한 일반 사용자
- Q3 경쟁력: 간단하고 빠른 의견 수집
- Q4 규모: 소규모 MVP (먼저 핵심만)

### B. 사용 환경 (Q5-Q10)
- Q5 지역: 국내
- Q6 플랫폼: 웹
- Q7 동시접속: ~100명
- Q8 배송: 무관
- Q9 결제: 무관
- Q10 PG사: 무관

### C. 기능 상세 (Q11-Q15)
- Q11 핵심 기능: 피드백 제출 + 본인 피드백 목록 조회 (이 둘만)
- Q12 부가 기능: 없음 (MVP)
- Q13 관리 기능: 없음 (MVP, 추후)
- Q14 비즈니스 규칙: 로그인한 사용자만 제출 가능, 별점 1~5
- Q15 보안: JWT 인증 필수

### D. 조직/일정 (Q16-Q19)
- Q16 팀 규모: 1인
- Q17 출시 일정: 2주
- Q18 법무/재무: 무관
- Q19 운영 담당: 본인

### 종료 신호
"개발 시작해" — 추가 질문 없이 기획서 작성으로 전환
