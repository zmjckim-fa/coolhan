# POS 시스템 - 핵심 기능 (POS System - Core Features)

## 개요

POS 시스템의 필수 기능, 선택 기능, 그리고 상황별 기능을 명시합니다.

---

## 1. 거래 관리 (Transaction Management)

### 1.1 거래 생성 및 처리 (필수)
- [ ] 새 거래 생성
- [ ] 거래 활성화 (상품 추가 가능 상태)
- [ ] 거래 타임스탐프 자동 기록
- [ ] 거래 ID 자동 생성
- [ ] 판매원 ID 기록
- [ ] 계산대 ID 기록

### 1.2 상품 입력 (필수)
- [ ] 바코드 스캔 입력
- [ ] 상품 코드 수동 입력
- [ ] 상품명으로 검색 및 선택
- [ ] 수량 입력 (기본값 1)
- [ ] 상품 가격 자동 조회
- [ ] 세율 정보 자동 포함
- [ ] 거래 항목 목록에 추가

### 1.3 거래 항목 관리 (필수)
- [ ] 항목별 수량 변경
- [ ] 항목 삭제
- [ ] 항목 가격 수정 (권한 필요)
- [ ] 모든 항목 삭제 (거래 초기화)
- [ ] 항목별 소계 자동 계산
- [ ] 현재까지의 합계 표시

### 1.4 거래 완료 (필수)
- [ ] 결제 처리
- [ ] 거스름돈 계산
- [ ] 거래 기록 저장
- [ ] 거래 상태를 "완료"로 변경
- [ ] 다음 거래 초기화
