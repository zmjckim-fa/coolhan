# BLOCKED: 운영자만 할 수 있는 일

> 키, 계정, 승인, 비용이 드는 일은 기능을 모두 끝낸 뒤 이 표에 모아 한 번에 알린다. 그 전에는 가짜 외부 서버와 기본값으로 끝까지 진행한다.

| 항목 | 왜 사람이 | 되면 이어서 할 일 | 필요한 시점 |
|---|---|---|---|
| 접근성 사람 확인 28행 (`docs/CHECKS.md` C11~C38) | 화면 낭독기로 듣기, 글자 200% 확대, 회색조, 실제 터치 기기, Safari와 Firefox는 사람이 기기로 봐야 한다 | 통과한 행의 비고에서 `manual`을 지우고 확인한 날짜와 기기를 적는다. 실패한 행은 결함으로 등록한다 | 실제로 쓰기 전 |
| `ADMIN_PASSWORD`, `SESSION_SECRET`, `SHOP_NAME` 값 | 가게의 실제 값이다 | `.env`에 넣고 서버를 띄운다(이름은 `.env.example`) | 실제로 쓰기 시작할 때 |
| 결정 D-10, D-11, D-12 (지금 영업 상태, 품절 표시, 메뉴 순서) | 지시 문장에 글자로 없는 기능이다. 기본값으로 포함했다 | 빼라고 하면 해당 컬럼, API, 단추를 지운다 | 언제든 |
| 가격 표시의 부가세 문구, 복구 목표, 가게 고유 색, 사진 | 가게마다 다르다. 기본값으로 진행했다(`docs/plan/`의 결정필요 줄) | 값을 받으면 설정이나 문구를 바꾼다 | 실제로 쓰기 전 |
| 배포 | 배포 허가 값이 `none`이다 | 허가와 서버가 정해지면 배포 스크립트를 기획한다 | 운영자가 정할 때 |
