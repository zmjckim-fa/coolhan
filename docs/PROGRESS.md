> 대화가 아니라 이 파일이 진실이다. 세션 시작·«이어서»·«계속»은 이 파일을 읽는 것으로 시작한다.
> 형식 검사: `node scripts/progress-check.js docs/PROGRESS.md` (C8). 고정 검증: `node scripts/checks-run.js`.

목표: 사용자가 지정한 표준 원칙을 쿨한 하네스의 기본 원칙으로 설치하고 기계 검사 가능한 부분을 게이트로 집행한다. 개발 원칙(최소 소스 · 단일 원천 S1–S8 · 진행 원장 · 고정 검증, G20)에 더해 2026-11-11 사용자 지시로 기획서 제작 표준(마스터 프롬프트, G21)을 포함한다. 같은 날 사용자 지시로 C:sites 전 프로젝트의 성공 방법과 실패 사례를 흡수해(현장 교훈, G22) 앞으로 만들 사이트에 적용하고 실패를 기계로 막는 일을 포함한다. 2026-11-17 사용자 지시로 운영자가 프로젝트마다 반복하던 명령을 상시 지시로 설치하고 모듈 저장소(00Module_site)를 기획의 필수 입력으로 쓰는 프로젝트 킷(G23)을 포함한다. 같은 날 사용자 지시로 상시 지시가 모든 세션과 모든 명령에 «쿨한으로»라는 말 없이 적용되게 하는 전역 설치(G24)를 포함한다. 2026-11-22 사용자 지시로 모듈 저장소(00Module_site)의 모듈을 더 잘 분리하고, 다른 프로젝트 폴더에서 고도화된 기능(문서 생성, 회원가입, 외부 API 연동, HS 코드 검색, 쇼핑몰, 관리자, 마이페이지, 디자인 스타일, 글로벌 우편번호)을 흡수하게 하는 일을 포함한다. 2026-11-24 사용자 지시로 만들어진 모듈의 취약점 점검과 수정, 모듈 사이 연동 확인, 디자인이 모듈과 함께 이관되고 이관하는 사이트에 조화롭게 바뀌는지의 확인, 작동과 입력과 저장 오류 제거를 모듈 하나씩 에이전트로 점검하는 일을 포함한다.
