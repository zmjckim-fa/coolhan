## 신뢰도

- 전부 **정적 분석**(공개 JS를 읽음)이다. 코드 실행과 실제 화면에서의 부품 목록·가격 대조는 하지 않았다.
- 항목마다 SOURCE(코드에서 직접 읽음, 줄 번호 병기) / PARTIAL(일부 확인) / GUESS(추정) 등급이 붙어 있다. 등급이 없으면 GUESS로 본다.
- 줄 번호는 prettier로 정리한 사본 기준이다(원본은 압축본이라 줄 번호가 다르다).
- 병렬 분석 4건 중 재고 폴링 주기, 장바구니 전송 필드, 세션 ID 생성 방식만 원본 코드와 직접 대조했다. 나머지는 각 문서의 증거 표기를 따른다.

## 사용 범위

- 우리 구성기를 설계할 때의 **기능·구조 참고** 자료다. smow의 코드, 이미지, 구성 JSON, 판매 가격, 재고 값은 이 폴더에도 우리 제품에도 넣지 않는다(문서에는 단가·재고 값을 옮기지 않았다).
- smow 코드의 규칙값은 USM 제품 사양에서 나온 것이라, 우리 규칙은 **공급사 부품표·조립 규칙으로 확정**한다. 이 문서의 값은 대조 후보다.
- USM 형상 재현과 상표 사용은 법률 검토가 필요하다.

## 원본 보관 안 함, 다시 받는 법

원본 JS는 저작물이라 저장소에 넣지 않았다. 다시 확인하려면 브라우저에서 페이지를 열고 개발자 도구의 Sources/Network에서 아래 파일을 본다(주소 앞부분 `https://www.smow.de/configurator/usm/haller/`).
- `_next/static/chunks/14xezdwz4pjta.js` (앱 본체, 약 880 KB, three.js 포함)
- `_next/static/chunks/0pv910lfhfhfu.js` (부품·단가표), `0sqfjbgv28kbx.js` (상수·enum), `13lzs0_g8pri-.js` (부속·색)
- `configs/35-23.json` (칸 미리보기 40종), `fonts/droid_sans_regular.typeface.json`
청크 파일명은 smow가 배포를 바꾸면 달라질 수 있다.

## 제작을 결정할 때 먼저 필요한 것

1. 공급사 부품표·단가표·조립 규칙·색상표·치수 도면(요청 컬럼은 `parts/C_부품표_체계.md` 6절). 운영자가 받을 수 있다고 확인함.
2. 우리 쪽 서버 재계산 설계(smow는 가격을 브라우저에서 계산해 보낸다. 서버 재검증 여부는 코드로 확인되지 않음).
3. 가격 검증 기준: 더리움 상품 880개 구성가(`docs/furniture-research/thereum/thereum_catalog.sqlite`)와 계산 결과의 일치율.
4. 주문 연결 방식: 카페24 개인결제창 또는 자체 결제.
5. 법률 검토: 형상 재현, 상표 사용.
6. 검증이 안 된 부분: 실제 화면 조작 대조, 서버 로직, 3D 파일(금고 glTF, 텍스처).
