# 다국어 국제 학술논문 작성 프레임워크
## Multilingual International Journal Standards (6 Languages)

**목표:** 같은 연구를 6개 언어로 고품질 학술논문으로 작성 가능하게 하기

**지원 언어:** English (EN), 中文 (ZH), 日本語 (JA), 한국어 (KO), Español (ES), Deutsch (DE)

---

## Part 1: 다국어 출판 전략

### 1.1 어떤 저널이 다국어를 지원하는가?

```
TIER 1: 다국어 초록 필수 (Nature, Science, PNAS)
  Requirement: 영어 본문 + 모국어 초록
  Formats: English main, 한글/日本語/中文 abstract (5-10개 저널)
  
TIER 2: 다국어 초록 권장 (eLife, PLOS ONE)
  Format: 영문 + 저자 선택 언어 초록
  
TIER 3: 다국어 서포트 (Frontiers in All Series)
  Format: 영문 본문 + 6개 언어 요약
  
SPECIAL: Open Access Journals
  PLOS Biology, Scientific Reports, Nature Communications
  다국어 초록 우대 (SEO 위해)
```

### 1.2 출판 경로 선택

```
경로 A: 단일 저널 + 다국어 초록
  Step 1: 영문 완성 (4000 words)
  Step 2: 전문 번역자 5명 고용 (각 언어별)
  Step 3: Nature에 영문+초록 함께 제출
  Timeline: 3개월
  Cost: $3,000-5,000 (번역비)

경로 B: 영문 먼저 + 이후 다국어 버전
  Step 1: 영문을 Nature/Science에 제출
  Step 2: Acceptance 후 다국어 버전 발행 (협력 저널)
  Step 3: 각 언어별로 국내 저널에 동시 발표
  Timeline: 6-12개월 (peer review 포함)
  이점: 한 번의 peer review로 6개 버전 얻음

경로 C: 완전 다국어 출판 (권장)
  Step 1: 6개 언어를 동등하게 작성
  Step 2: Open access 저널에 투고
  Step 3: 6개 언어 모두 공개
  Timeline: 4-6개월
  이점: 전 세계 접근성, 높은 인용 (multilingual bonus)
```

## Part 2: 각 언어별 학술 관례

### 2.1 English (International Standard)

**특징:**
- Passive voice 선호 (과학적 객관성)
- Future perfect tense 많음
- 짧은 문장 (주어-동사-목적어)
- Technical terms 명확히 정의

**예시 (Methods):**
```
The tokens were extracted from the manuscript using a parsing protocol
developed specifically for EVA notation. Character frequencies were computed
using standard corpus linguistics methods. Statistical significance was
determined using χ² tests with Bonferroni correction for multiple comparisons.
```

### 2.2 中文 (Simplified Chinese - Mainland)

**특징:**
- Subject-verb-object 어순 엄격함
- 수치와 단위 구분 명확
- Passive voice 적음 (자동으로 번역 안 됨)
- 문맥에 따라 주어 생략 가능

**예시 (Methods):**
```
使用专为EVA符号开发的解析协议从手稿中提取token。采用标准语料库语言学方法
计算字符频率。使用χ²检验和Bonferroni多重比较校正确定统计显著性。
```

**주의:** Simplified vs Traditional 선택
- Mainland 저널 → Simplified only
- Taiwan 저널 → Traditional only
- 국제 저널 → Simplified preferred (ISO standard)

### 2.3 日本語 (Japanese)

**특징:**
- Passive form (～られた) 필수 (scientific tone)
- Polite form (～です) 사용
- Particles (は, が, を, に) 정확히 사용
- Kanji/Hiragana/Katakana 혼합

**예시 (Methods):**
```
EVA表記に特別に開発された解析プロトコルを用いてトークンが手稿から抽出された。
標準的なコーパス言語学的方法を用いて文字頻度が計算された。χ²検定とBonferroni
多重比較補正を用いて統計的有意性が決定された。
```

**주의:** 
- Academic Japanese는 formal noun forms (～こと、～の) 많음
- 漢語 (한자 어휘) 학술용어에 70% 이상

### 2.4 한국어 (Korean)

**특징:**
- 의존명사 많음 (것, 수, 방법)
- Particle 체계 (이/가, 을/를, 에/에서)
- Honorific 학술 표현 (～되었다, ～보인다)
- 종결어미 문체에 따라 변화

**예시 (Methods):**
```
EVA 기호에 맞추어 개발된 파싱 프로토콜을 사용하여 필사본에서 토큰이 추출되었다.
표준적인 코퍼스 언어학 방법을 이용하여 문자 빈도가 계산되었다. χ² 검정과
Bonferroni 다중비교 수정을 사용하여 통계적 유의성이 결정되었다.
```

**주의:**
- Academic Korean은 ～었다, ～되다 형태 선호
- 영어 수입어는 한글 표기 (파싱, 토큰, 프로토콜)

### 2.5 Español (Spanish)

**특징:**
- Subjunctive mood 학술용으로 사용
- Reflexive verbs 많음 (se extraen, se calculan)
- Gender agreement (masculine/feminine) 중요
- Accent marks 반드시 포함

**예시 (Methods):**
```
Se extrajeron tokens del manuscrito utilizando un protocolo de análisis
desarrollado específicamente para la notación EVA. Se calcularon frecuencias
de caracteres utilizando métodos estándar de lingüística de corpus.
Se determinó la significancia estadística utilizando pruebas χ² con
corrección de Bonferroni para comparaciones múltiples.
```

**주의:**
- Latin American Spanish vs Spain Spanish (어휘 차이)
- 논문은 Spain Spanish standard 선호

### 2.6 Deutsch (German)

**특징:**
- Compound nouns (단어 조합으로 새 단어 생성)
- Case system (Nominativ, Akkusativ, Dativ, Genitiv)
- Verb position (subordinate clause에서 마지막)
- Gender agreement (der/die/das)

**예시 (Methods):**
```
Mithilfe eines speziell für die EVA-Notation entwickelten Parsing-Protokolls
wurden Token aus dem Manuskript extrahiert. Zeichenhäufigkeiten wurden mit
standardmäßigen Methoden der Korpuslinguistik berechnet. Statistische
Signifikanz wurde mithilfe von χ²-Tests mit Bonferroni-Korrektur für
Mehrfachvergleiche bestimmt.
```

**주의:**
- German compound nouns는 구분할 수 없음 (하나의 단어)
- Capitalization of nouns 반드시 지킬 것

## Part 3: 다국어 초록 작성 (Abstracts)

### 3.1 Abstract 길이 기준

```
English:     150-200 words (Nature), 250-300 words (full abstract)
中文:        200-300字 (characters)
日本語:      200-300字 (characters)
한국어:      200-300자 (characters)
Español:     150-250 palabras
Deutsch:     150-250 Wörter

핵심: 같은 정보량을 각 언어로 표현
```

### 3.2 Abstract 구조 (모든 언어 동일)

```
1. BACKGROUND (배경) - 15-20%
   ∟ What is the problem? Why should we care?
   
2. METHODS (방법) - 20-25%
   ∟ What did you do? How did you do it?
   
3. RESULTS (결과) - 30-35%
   ∟ What did you find? (Main findings only)
   
4. CONCLUSION (결론) - 15-20%
   ∟ What does it mean? Why does it matter?
```

### 3.3 실제 예시: 보이니치 논문 추상

#### English
```
Background: The Voynich Manuscript, a 15th-century undeciphered manuscript,
has resisted interpretation for over 500 years. Existing hypotheses—natural
language, substitution cipher, or artificial language—assume the manuscript
contains recoverable text. However, an alternative exists: the manuscript may
encode a pre-modern taxonomic or reference system.

Methods: We conducted quantitative structural analysis on 7,063 tokens across
112 folios using corpus linguistics methods. We computed character frequencies,
entropy metrics, position-based constraints, and section-level statistics,
comparing Voynich patterns to English text, taxonomic catalogs, botanical
descriptions, ciphers, and random text.

Results: Voynich exhibits structural patterns incompatible with natural
language but consistent with formal systems: 96.3% of tokens end with 8
constrained characters (English: 75%, catalogs: 89%); vocabulary divergence
across sections is 23% (English: 5%, catalogs: 35%); token family clustering
occurs at 9% rate (English: 2%). Entropy metrics (2-gram H=6.14) fall between
natural language (H=10.5) and formal systems (H=7.8).

Conclusion: While not claiming decipherment, our findings suggest Voynich's
structure is compatible with a reference system hypothesis. This reframes the
research question from "What language/cipher?" to "What information system?"
and invites collaboration from manuscript studies, information history, and
paleography disciplines.
```

#### 中文
```
背景：15世纪的《伏尼契手稿》是一份未破译的手稿，已抵抗破译500多年。
现有假说假设手稿包含可恢复的文本。然而，另一种可能性存在：该手稿可能
编码了前现代分类法或参考系统。

方法：我们使用语料库语言学方法对112个folio中的7,063个token进行了
定量结构分析。我们计算了字符频率、熵度量、位置约束和部分级统计数据，
将伏尼契模式与英文文本、分类目录、植物学描述、密码和随机文本进行了
比较。

结果：伏尼契表现出与自然语言不兼容但与正式系统兼容的结构模式：
96.3%的token以8个受限字符结尾（英文：75%，目录：89%）；部分间词汇
差异为23%（英文：5%，目录：35%）；token族群聚集率为9%（英文：2%）。
熵度量（2-gram H=6.14）介于自然语言（H=10.5）和形式系统（H=7.8）之间。

结论：虽然没有宣称破译，但我们的发现表明伏尼契的结构与参考系统假说
兼容，这将研究问题从"什么语言/密码？"重新界定为"什么信息系统？"
```

#### 日本語
```
背景：15世紀の《ヴォイニッチ手稿》は500年以上の解読に抵抗してきた
未解読手稿である。既存の仮説は手稿がテキストを含むと仮定している。
しかし、別の可能性が存在する：手稿は前近代の分類法またはレファレンス
システムをエンコードしているかもしれない。

方法：コーパス言語学的方法を用いて112の葉にわたる7,063個のトークンに
対して定量的構造分析を実施した。文字周波数、エントロピー度量、位置
ベースの制約、セクションレベルの統計を計算し、ヴォイニッチパターンを
英文、分類目録、植物学的記述、暗号、および無作為テキストと比較した。

結果：ヴォイニッチは自然言語と非互換だが形式システムと互換性のある
構造パターンを示す：トークンの96.3%が8つの制限文字で終わる
（英語：75％、目録：89％）；セクション間の語彙の発散は23％
（英語：5％、目録：35％）；トークンファミリクラスタリングは9％
（英語：2％）。エントロピー度量（2-gram H=6.14）は自然言語
（H=10.5）と形式システム（H=7.8）の間に位置する。

結論：解読を主張しないが、本結果はヴォイニッチの構造が参照システム
仮説と互換性があることを示唆している。これは研究課題を
「言語/暗号は何か？」から「情報システムは何か？」へと再定義する。
```

#### 한국어
```
배경：15세기 《보이니치 필사본》은 500년 이상 미해독 상태의 필사본이다.
기존 가설들은 필사본에 복구 가능한 텍스트가 포함되어 있다고 가정한다.
그러나 다른 가능성이 존재한다: 필사본은 전근대 분류법 또는 참조 시스템을
암호화하고 있을 수 있다.

방법：코퍼스 언어학 방법을 사용하여 112개 folio에 걸친 7,063개 토큰에
대한 정량적 구조 분석을 수행했다. 문자 빈도, 엔트로피 지표, 위치 기반
제약, 섹션 수준 통계를 계산했으며, 보이니치 패턴을 영문 텍스트, 분류
목록, 식물학 설명, 암호, 무작위 텍스트와 비교했다.

결과：보이니치는 자연 언어와는 비호환이지만 형식 시스템과는 호환되는
구조 패턴을 보인다: 토큰의 96.3%가 8개 제약 문자로 끝남
(영어: 75%, 목록: 89%); 섹션 간 어휘 차이 23%
(영어: 5%, 목록: 35%); 토큰 계열 군집화 9% (영어: 2%).
엔트로피 지표(2-gram H=6.14)는 자연 언어(H=10.5)와 형식 시스템(H=7.8)
사이에 위치한다.

결론：비록 해독을 주장하지는 않지만, 본 연구의 결과는 보이니치의
구조가 참조 시스템 가설과 호환될 수 있음을 시사한다. 이는 연구 질문을
"어떤 언어/암호인가?"에서 "어떤 정보 시스템인가?"로 재설정한다.
```

#### Español
```
Antecedentes: El Manuscrito Voynich, un manuscrito sin descifrar del
siglo XV, ha resistido la interpretación durante más de 500 años. Las
hipótesis existentes asumen que el manuscrito contiene texto recuperable.
Sin embargo, existe una alternativa: el manuscrito podría codificar un
sistema taxonómico o de referencia premoderno.

Métodos: Realizamos análisis estructural cuantitativo en 7,063 tokens
en 112 folios utilizando métodos de lingüística de corpus. Calculamos
frecuencias de caracteres, métricas de entropía, restricciones basadas
en posiciones y estadísticas a nivel de sección, comparando patrones
Voynich con texto en inglés, catálogos taxonómicos, descripciones
botánicas, cifras y texto aleatorio.

Resultados: Voynich exhibe patrones estructurales incompatibles con
lenguaje natural pero consistentes con sistemas formales: 96.3% de los
tokens terminan con 8 caracteres restringidos (inglés: 75%, catálogos:
89%); la divergencia de vocabulario entre secciones es 23% (inglés: 5%,
catálogos: 35%); la agrupación de familias de tokens ocurre al 9%
(inglés: 2%). Las métricas de entropía (2-gram H=6.14) se encuentran
entre lenguaje natural (H=10.5) y sistemas formales (H=7.8).

Conclusión: Sin afirmar el desciframiento, nuestros hallazgos sugieren
que la estructura Voynich es compatible con la hipótesis de sistema de
referencia. Esto redefine la pregunta de investigación de "¿Qué
lenguaje/cifra?" a "¿Qué sistema de información?"
```

#### Deutsch
```
Hintergrund: Das Voynich-Manuskript, ein ungeklärt gebliebenes Manuskript
des 15. Jahrhunderts, hat sich über 500 Jahre dem Verständnis widersetzt.
Bestehende Hypothesen nehmen an, dass das Manuskript wiederherstellbaren
Text enthält. Es gibt jedoch eine Alternative: Das Manuskript könnte ein
vormodernes Taxonomie- oder Referenzsystem kodieren.

Methoden: Wir führten quantitative Strukturanalysen an 7.063 Token über
112 Seiten unter Verwendung von Methoden der Korpuslinguistik durch. Wir
berechneten Zeichenhäufigkeiten, Entropiemaße, positionsbasierte Einschränkungen
und Statistiken auf Abschnittsebene und verglichen Voynich-Muster mit
englischem Text, taxonomischen Katalogen, botanischen Beschreibungen,
Chiffren und Zufallstext.

Ergebnisse: Voynich zeigt Strukturmuster, die mit natürlicher Sprache
unvereinbar, aber mit formalen Systemen vereinbar sind: 96,3% der Token
enden mit 8 eingeschränkten Zeichen (Englisch: 75%, Kataloge: 89%);
Vokabulardivergenz zwischen Abschnitten beträgt 23% (Englisch: 5%,
Kataloge: 35%); Token-Familien-Clusterung tritt mit 9% auf (Englisch: 2%).
Entropiemaße (2-Gramm H=6,14) fallen zwischen natürliche Sprache (H=10,5)
und formale Systeme (H=7,8).

Schlussfolgerung: Obwohl nicht als Entzifferung beansprucht, deuten unsere
Ergebnisse darauf hin, dass die Voynich-Struktur mit der Hypothese des
Referenzsystems kompatibel ist. Dies definiert die Forschungsfrage von
"Welche Sprache/Geheimschrift?" zu "Welches Informationssystem?" neu.
```

## Part 4: 번역 & 검수 프로세스

### 4.1 다국어 검수 체크리스트

```
각 언어별로:

[ ] Grammar check
    - Native speaker 검수 (not translator)
    - Academic database (한국학술정보, CiNii, etc.) 비교
    
[ ] Terminology consistency
    - 같은 용어가 같은 번역으로 사용되었는가?
    - 과학 용어의 정의가 모든 언어에서 일치하는가?
    
[ ] Clarity
    - 원문의 의도가 보존되었는가?
    - 학술용으로 적절한가?
    - 문화적 맥락에 맞는가?
    
[ ] Formatting
    - 수식/참고문헌 형식이 언어별 표준을 따르는가?
    - Character limit (초록 길이) 만족하는가?
    
[ ] Cultural Adaptation
    - 직역 vs 의역 적절히 분배되었는가?
    - 관례적 표현 사용되었는가?
```

### 4.2 번역 품질 평가 (TQA)

```
점수: 1-5 (5=최고)

Accuracy (정확성):
  5: 완벽한 의미 이전
  3: 80% 이상 의미 이전
  1: 주요 오류 있음

Terminology (용어 일관성):
  5: 일관되게 표준 용어 사용
  3: 90% 일관성
  1: 불일치 多

Clarity (명확성):
  5: 원문과 동등한 명확성
  3: 약간의 개선 필요
  1: 모호함

Target Language Appropriateness (언어 적절성):
  5: 학술용으로 자연스러움
  3: 약간의 어색함
  1: 비학술적

최종 합격 기준: 평균 ≥ 4.0 / 5.0
```

```

## Part 6: 다국어 논문의 이점

```
✅ BENEFITS:

1. Global Reach
   - 6개 언어 커버 → ~80% 세계 인구
