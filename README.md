# 🎯 CoolHan - AI 기반 개발 자동화

> **모국어로 완벽한 개발을 자동화하세요**

---

## 🚀 CoolHan이란?

CoolHan은 **모국어로 자연스럽게 개발 지시를 내리면, AI가 규격부터 테스트까지 완벽하게 처리하는 자동화 프레임워크**입니다.

### 핵심
- ✅ 50+ 언어 자동 지원 (자동 감지)
- ✅ 한국어, 영어, 일본어, 중국어 등 자연 언어로 명령
- ✅ 자동 규격 생성 → 코드 구현 → 검증 → 배포
- ✅ 100% 규격 준수 보장

---

## ⚡ 3분 빠른 시작

### 1단계: Clone
```bash
git clone https://github.com/zmjckim-fa/coolhan.git
cd coolhan
```

### 2단계: 설치
```bash
npm install
```

### 3단계: 사용 시작
```bash
쿨한으로 사용자 로그인 기능 추가해
```
