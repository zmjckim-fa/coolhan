## 구현 범위 (Scope)

### Phase 1: 핵심 기능만
1. **API Endpoints**
   - `POST /api/feedback` - 피드백 제출
   - `GET /api/feedback` - 피드백 목록 조회 (인증된 사용자)
   - `GET /api/feedback/:id` - 피드백 상세 조회

2. **데이터베이스 테이블**
   ```sql
   CREATE TABLE feedback (
     id UUID PRIMARY KEY,
     user_id UUID NOT NULL,
     message TEXT NOT NULL,
     rating INT (1-5),
     status ENUM('new', 'read', 'responded') DEFAULT 'new',
     created_at TIMESTAMP DEFAULT NOW(),
     updated_at TIMESTAMP
   );
   ```

3. **기본 검증**
   - 메시지는 필수 (1-500자)
   - 레이팅은 선택 (1-5)
   - 사용자 인증 필수

4. **에러 처리**
   - 400: 유효하지 않은 입력
   - 401: 미인증
   - 404: 피드백 없음
   - 500: 서버 오류

### Phase 2: 테스트
- 단위 테스트 (Unit Tests)
- 통합 테스트 (Integration Tests)
- 성공 시나리오: 피드백 제출, 목록 조회
- 실패 시나리오: 유효성 검사, 인증 오류
