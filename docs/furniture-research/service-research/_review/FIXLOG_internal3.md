# 내부 운영 기준서 3차 수정 기록

대상: deliverables/build_internal.js, 결과 내부운영기준서_해외가구_판매_설치.docx. 기준: R11_cross_v3.md의 내부 문서 해당 결함(높음 F1, F2, F4와 값 누락 낮음 4건, 행 42 인용), R9_public_v3.md의 N3-4·N3-5, FIX_DECISIONS.md D42·D45, FIXLOG_internal2.md의 값 추적 방식, 그리고 세 문서의 3차 수정 후 최신본(1_서비스규정.txt, 2_고객사용설명서.txt, 3_설치업체지침.txt를 세 docx에서 다시 덤프했다).
범위는 3차 검증이 지적한 치명·높음과 값 추적 갱신으로 한정했다. 추적표는 build_internal.js의 추적 데이터에서 생성하며 2장에 없는 행을 가리키면 빌드가 실패한다. 3차 수정 전 본(v3 폴더)과 최신본의 차이를 조항 순서로 대조해 바뀐 조항의 추적 항목을 고치고 새 항목을 추가했다.
