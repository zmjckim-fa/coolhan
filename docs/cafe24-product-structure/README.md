# 카페24 상품 입력 구조

2026-11-07. 운영자가 카페24 관리자에서 받은 파일 4종을 분석한 결과다. 파일에서 읽은 것만 적었고, 읽지 못한 것은 "미확인"으로 표시했다.

## 1. 받은 파일 4종

| 파일 | 내용 | 쓰임 |
|---|---|---|
| 업로드 템플릿 `excelUploadProductDefault` | 90개 컬럼, 샘플 상품 3행 | **상품 업로드의 기준 구조** |
| 상품 다운로드 `상품ohsomeplus_…` | 88개 컬럼, 상품 4행 | 실제 입력 예시 |
| 상품 코드 목록 `ProductCodeList` | 1,588건(구분, 코드, 이름) | 제조사·공급사·브랜드 등 코드 사전 |
| 주문 다운로드 `주문ohsomeplus_…` | 28개 컬럼, 주문 1행 | 주문·원가·환불 구조 참고(고객 개인정보가 있어 저장소에는 넣지 않음) |

주문 다운로드의 컬럼명: 취소구분, 매출경로, 주문일시, 주문경로 주문번호, 주문자명, 주문상품명(기본), 상품옵션(기본), 수량, 총 결제금액, 총 상품구매금액, 수령인 정보, 통관정보, 배송메시지, 공급원가, 총재고수량, 운송장번호, 상품 매입가, 마켓할인 기타, 판매가, 총 주문금액, 총 실제 환불금액. 결산과 WMS 연동에서 다시 본다.

## 2. 핵심 사실

1. **업로드는 템플릿 90컬럼 순서를 따라야 한다.** 다운로드 파일(88컬럼)은 컬럼이 달라서 그대로 업로드 파일로 쓸 수 없다.
   - 템플릿에만 있는 컬럼 5개: 상품 상세설명, 모바일 상품 상세설명 설정, 모바일 상품 상세설명, 이미지등록(추가), 메모
   - 다운로드에만 있는 컬럼 3개: 제조사명, 브랜드명, 부피무게(kg)
   - 공통 85개 컬럼은 순서도 서로 다르다.
2. **코드는 쇼핑몰마다 다르다.** 코드 목록은 이 쇼핑몰(ohsomeplus)의 값이다. 우리 쇼핑몰을 만든 뒤 우리 몰에서 코드 목록을 새로 받아야 한다.
   | 구분 | 코드 형식 | 건수 |
   |---|---|---|
   | 제조사 | `M0000000` | 104 |
   | 공급사 | `S0000000` | 58 |
   | 브랜드 | `B0000000` | 111 |
   | 트렌드 | `T0000000` | 2 |
   | 자체분류 | `C000000A` | 1 |
   | 원산지 | 숫자 코드 | 504 |
   | 상품구분(해외통관) | `AAAA0000` 형식 | 808 |
3. **상품분류 번호(카테고리)는 코드 목록에 없다.** 관리자에서 카테고리를 만든 뒤 번호를 확인해 입력한다.
4. **상품 코드(`P0000CQQ`)는 카페24가 부여한다.** 새 상품은 상품코드를 비워 두는 것으로 보이나, 비워도 되는지는 미확인이다.

## 3. 입력 규칙 (템플릿 예시와 다운로드 파일에서 관찰)

| 항목 | 규칙 | 예 |
|---|---|---|
| 여러 값 | `\|` 로 구분 | `26\|29\|30` |
| 상품분류 3개 컬럼 | 항목 수가 같아야 함(번호, 신상품영역, 추천상품영역) | `26\|29` / `N\|Y` / `N\|Y` |
| 옵션 입력 | `옵션이름{값\|값}//옵션이름{값\|값}` | `색상{빨강\|파랑}//사이즈{55\|66}` |
| 필수여부 | 옵션 개수만큼 `T\|F` | 옵션 2개 → `T\|F` |
| 색상 설정 | 옵션 값 개수만큼 `{#hex\|#hex}` | `{#000000}` |
| 과세구분 | `종류\|세율` | `A\|10` |
| 가격 | 상품가는 판매가의 부가세 제외 금액으로 보임(판매가 3,490,000에 상품가 3,172,727). 과세 10%일 때의 관찰 | |
| 이미지 | 업로드된 파일의 경로를 입력 | `202610/….jpg` |

이 규칙 중 위 3가지(분류 항목 수, 옵션 형식, 필수여부 개수)는 `cafe24_product_csv.py`에서 검사하고, 받은 실제 행 7개(템플릿 3행, 다운로드 4행)에서 위반 0건을 확인했다.

## 4. USM 상품을 이 구조에 넣는 방법

| USM 요소 | 입력 방법 | 이 파일로 가능한가 |
|---|---|---|
| 크기·구성(1×2, 2×2 등) | 상품 1행 | 가능 |
| 색 | 옵션입력 `색상{...}` | 옵션 이름은 가능 |
| 색별 가격 차이·재고 | 품목(variants) 단위 값 | **컬럼 없음.** API 필요(미확인) |
| 부속(추가구성상품) | 추가구성상품 | **컬럼 없음.** 관리자 또는 API 필요(미확인) |
| 제작주문 철회 제한 동의 | 상품 상세·결제 안내 | 상품결제안내·교환/반품안내 컬럼으로 문구 입력은 가능, 동의 기록은 별도 |

즉 이 CSV 업로드만으로는 **색별 가격과 부속이 들어가지 않는다.** 이 두 가지는 카페24 Admin API로 넣어야 하고, 그 필드와 호출 한도는 개발자센터 문서에서 확인해야 한다(검색으로는 찾지 못함).

## 6. 아직 모르는 것

- 컬럼별 코드 값의 의미(예: 주문수량 제한 기준 `O`, 적립금 구분 `W`/`P`, 품목 구성방식 `T`/`F`, 옵션 표시방식 `S`/`C`). 값 목록만 관찰했다.
- 필수 컬럼이 무엇인지.
- Admin API의 상품 등록·품목·추가구성상품 필드와 호출 한도.
- API 업로드 자체는 만들지 않았다. 카페24 앱 등록과 인증 정보가 있어야 한다.

## 7. 더리움 구성 import 파일 (2026-11-07)

운영자 지시로 더리움에서 조사한 데이터 전체를 카페24 업로드 엑셀로 만들었다. 재생성: `python make_import_from_thereum.py` (원본: `furniture-research/thereum/`).

**파일** (`import/`)
- `카페24_상품_import_USM_Haller_더리움구성.xlsx`: 첫 시트 `상품`은 카페24 업로드 형식(90컬럼, 848개 상품). 나머지 11개 시트에 조사한 데이터 전부가 들어 있다.
- `…더리움구성.csv`: `상품` 시트만(업로드 전용). 업로드할 때 xlsx의 첫 시트만 읽는지 확인되지 않아서 따로 만들었다.
- `색별가격_API용.csv`: 색 선택 시 단가(색 11,190행).

**`상품` 시트의 값**
| 컬럼 | 값 |
|---|---|
| 상품명 | 더리움 사이트의 상품명 그대로(예: `USM Haller/유에스엠 할러 - 1x2(1단오픈)`). 848개 모두 서로 다름 |
| 상품명(관리용) | `상품번호 \| 종류까지 붙인 정식명`(예: `26 \| 1x2(1단오픈) 수납 모듈`) |
| 상품 요약설명 | 종류와 구성(예: `수납 모듈 · 가로 1칸 × 세로 2단`) |
| 상세설명, 간략설명 | 더리움 상품 설명 원문(838개. 10개는 원문에 설명이 없음) |
| 이미지 | 더리움 대표 이미지 주소 836개, 구성기 이미지(추가) 234개. 상세·목록·작은목록·축소에 같은 주소 |
| 판매가·소비자가·상품가 | 더리움 표시가(상품가 = 판매가÷1.1 내림) |
| 옵션 | `색상{…}` 804개, 색상값 798개 |
| 검색어·SEO | 더리움 SEO 값에서 `더리움` 단어만 뺀 것 |
| 메모 | **더리움 상품 링크(맨 앞)**, 더리움 상품번호, 코드, 종류·구성, 납기, 이행 방식, 최적할인가, 카테고리, 후기 수·평점 |
| 진열·판매 | 둘 다 `N` |
| 비워 둔 값 | 상품분류 번호, 원산지, HS코드, 중량, 공급가, 영문 상품명, 안내 문구, 배송 설정 |

**나머지 시트:** 더리움_링크(상품명, 더리움 상품 링크와 대표 이미지 링크를 클릭 가능한 형태로 정리), 더리움_원본상품(880개, 사이트 정보·SEO·후기 포함), 색상_SKU(11,318), 색상표, 카테고리, 부속상품(811), 상품_부속연결(1,721), 부속옵션(141,039), 구성기_이미지(19,278), 구성기_치수, 구성기_바퀴, 브랜드.

**주의할 점**
- **이미지와 설명은 더리움의 저작물이다.** 더리움 서버 주소를 그대로 넣었다. 12개 상품은 페이지에 "이 상품 이미지는 더리움의 자산입니다"라고 적혀 있어서 이미지를 넣지 않고 그 문장도 뺐다(`USE_IMAGES = False`로 이미지 전체를 뺄 수 있다). 진열(`N`)하기 전에 우리 자료로 바꾸는 것이 안전하다.
- 이미지 주소가 카페24 업로드에서 받아지는지는 확인하지 못했다(샘플 15개는 응답 200). 더리움 쪽 주소가 바뀌거나 막히면 끊긴다.
- 상품명 앞의 `[국내재고]`, `[입고예정]`, `[B급]`은 더리움의 재고 상태다. 우리 몰에는 재고가 없다.
- 상세설명은 텍스트뿐이다. 더리움 상세 페이지의 이미지 주소는 수집하지 않았다.
- 색별 가격 차이와 부속(추가구성상품)은 `상품` 시트에 넣을 수 없다. 해당 데이터는 시트로만 담겨 있다.
- 회원 전용 32개는 `더리움_원본상품` 시트에만 있다.
